SERVER STATUS
Go to 🔧 SETUP tab to connect your server.
HOW IT WORKS: All data is stored only on your server via save.php. No localStorage is used for site data — every save goes directly to your VM.
🔧 SERVER ENDPOINT CONFIG
Your server needs one PHP file that handles both reading and writing:

GET /api/save.php — returns the full JSON data
POST /api/save.php — receives JSON and saves it
STEP 1 — UPLOAD save.php TO YOUR SERVER

Upload save.php to your web root, e.g.:

/var/www/html/api/save.php
STEP 2 — ENTER YOUR SERVER URL

Base URL — no trailing slash.

Endpoint: https://yourdomain.com/api/save.php
STEP 3 — WRITE PASSWORD

The secret password set inside save.php to authorise write requests.

STEP 4 — SAVE & TEST
