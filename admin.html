🔧 SERVER ENDPOINT CONFIG
Point the admin panel to your own VM/server. Your server needs two endpoints:
GET /api/data.json — returns the full data
POST /api/save.php — receives JSON body and saves it

See the save.php file bundled with this panel for a ready-made PHP script.
STEP 1 — UPLOAD save.php TO YOUR VM
Upload save.php to your web root (e.g. /var/www/html/api/save.php). It handles both reading and writing the JSON file.
STEP 2 — ENTER YOUR SERVER URL
The panel will use /api/save.php on this domain.
STEP 3 — ENTER WRITE PASSWORD
A secret password set in save.php to prevent unauthorized writes.
STEP 4 — SAVE & TEST
